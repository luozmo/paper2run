# 03: 证据编号与来源追溯

**What to build:** 学生从报告正文中的信息和参数对照定位到对应证据，在集中证据章节阅读上游提供的来源、位置、原文引用及链接，并能识别没有提供证据的内容。

**Blocked by:** 02 — 完整分析内容展示。

**Status:** ready-for-agent

- [ ] 为存在证据的论文信息、仓库候选、依赖、运行入口、实验条件和参数对照关联证据编号，覆盖现有模型实际能够表达的关联。
- [ ] 末尾证据章节集中展示来源、已有论文页码或仓库文件位置、已有原文引用和链接。
- [ ] 相同证据在正文多次使用时复用编号；正文每个证据编号都能对应到集中证据章节。
- [ ] Markdown 与 Word 对同一分析数据采用一致的证据编号和引用对应关系。
- [ ] 对没有提供证据的事实明确标注；模型未给某项事实提供关联证据的能力时，也不凭位置相邻或内容相似补造关联。
- [ ] 引用、页码、文件位置、链接等可选属性缺失时不编造；仍展示已有的证据内容。
- [ ] 保留原文引用、技术名称和已有位置含义，不执行联网核验，也不因存在编号而宣称事实已被独立验证。
- [ ] 使用重复证据、多个不同证据、缺少可选属性及完全没有证据的样例，从导出入口核对两种实际文档的引用对应和缺失标记。
- [ ] 完整数据、缺失数据、来源区别和冲突展示保持有效，现有项目测试保持通过。

本工单补齐工单 02 已展示内容的证据阅读路径，不引入新的上游模型、检索流程或事实判定。
