# 02: 完整分析内容展示

**What to build:** 学生打开任一格式的报告文档，即可阅读上游已提供的论文、仓库、依赖、运行方式、实验条件和参数对照，明确看到来源区别、数据冲突及尚缺的信息。

**Blocked by:** 01 — 基础双格式导出与文件保护。

**Status:** done

- [x] 概览仅概括上游已有的仓库状态、已提供的信息和待确认项，不增加模型推断或确定性结论。
- [x] 展示已有论文基本信息、候选仓库、选中仓库、官方状态和说明；仓库可用状态、官方状态与选中仓库分别沿用上游数据，不互相补造。
- [x] 将两处依赖分别标为“汇总依赖”和“仓库检查依赖”，保留名称、已有版本及用途等字段；不将汇总依赖擅自归为论文来源。
- [x] 同名依赖版本不同时两处记录均保留，不自动选版本或合并为确定结论。
- [x] 展示已有仓库结构说明、依赖清单信息、运行入口和运行命令；技术名称、路径和命令保持原文。
- [x] 展示论文实验条件，包括已有的数据集、模型、框架、硬件、训练设置和评测信息。
- [x] 参数对照分列论文值和仓库值，保留说明；一致、不一致、仓库缺失、论文缺失和无法确认等状态中文化并沿用上游判断。
- [x] 展示报告及嵌套仓库检查、参数对照中的缺失项和警告，保留可辨认的来源上下文。
- [x] 任一部分数据为空时保持报告可读，不把无数据表述成否定事实；完整数据和部分缺失数据都能生成两种报告文档。
- [x] 两种格式具有相同事实和章节；Word 使用适当表格与等宽命令文本。
- [x] 从公开导出入口使用完整、部分缺失和冲突样例核对实际文档内容，覆盖全部对照状态和两处依赖的版本差异；不依赖外部服务。
- [x] 工单 01 的文件保护与失败行为保持有效，现有项目测试保持通过。
